## Выполнение и проверка

- Семь UI-spec используют общую auto-фикстуру проверки pageerror; обычные synthetic session routes вынесены в mockSession, специальные ошибки auth/CSRF и изменяемые данные сценариев остались локальными.
- Пять real-наборов и UI используют общий вход/меню/выход. Preview сначала покидает режим чтения; выбор меню основан на role/aria-controls и aria-expanded.
- Статус сдачи ищется по её filename heading и header. Точные подписи полей, radio, select и region заменяют хрупкие CSS/позиции; проверки порядка истории/маршрута оставлены.
- tenant-isolation ждёт наблюдаемую отмену запроса вместо фиксированной секунды.
- QA замечания исправлены: сохранены точные href, отсутствие скрытых private links/controls. Пробный запуск выявил некорректный getByRole current (заменён пересечением с aria-current) и сокращённое exact-имя упражнения (уточнено по каталогу).
- Два прежних текста, недостижимых после падения на .pill, обновлены по текущим шаблонам: баннер предпросмотра и пустое ревью. Приведены к контракту тип HomeworkPage и number в фикстурах занятий; объект detail типизирован как Record.
