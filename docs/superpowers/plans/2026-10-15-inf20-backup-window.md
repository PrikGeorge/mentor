# INF-20 — сократить остановку backend при копировании

Владелец INF; смежное ревью B/INF и QA. База `a96fe5a`. Один смысловой коммит, без push и запуска копии рабочего контура.

Сейчас backend остановлен и SQL fence удерживается во время SHA256 всего локального снимка. После завершения `pg_dump --snapshot` и обеих `docker cp` локальные файлы больше не зависят от рабочего хранилища. Проверка и закрытие fence, затем возобновление ранее работавшего backend должны предшествовать вычислению hashes и сериализации manifest. `createdAt` фиксируется перед освобождением снимка. Копирование БД и объектов остаётся под остановкой и fence; maintenance lease удерживается до завершения всей операции.

- [x] Поведенческие тесты порядка, согласованности закрытого снимка и отказов: running/stopped backend, copy/fence/hash/start failures.
- [x] Перенести только вычисление manifest/hashes за возобновление; сохранить receipt, шифрование, offsite, restore verification и cleanup.
- [x] RED → GREEN, полный набор infra mocks, parser/diff; по необходимости отдельная синтетическая проверка fence.
- [x] Смежное B/INF и QA-ревью, эксплуатация/карта при изменении навигации, строка §0, локальный коммит.

Эта правка исключает стоимость обхода и хеширования локальных файлов из окна остановки. Время самого `pg_dump` и копирования остаётся; обещание нулевого простоя не даётся. Реальные данные и конфигурация не читаются. Открытые image remediation, Q-18 snapshot, runner daemon и practice fixture остаются отдельными gates.

Результат: RED показал hashes перед start; GREEN — 7 сценариев (`running-consistent-snapshot`, `already-stopped`, обе ошибки копирования, потеря fence, ошибка hash после resume, ошибка первого start с retry в finally). Проверяются исходные bytes/hash/size/counts после изменения и удаления live-фикстур, createdAt до Close fence, lease во время обработки и до квитанции, отсутствие успешной копии при ошибке. Все 13 infra mock-сценариев прошли в NTFS-копии; парсер 44 исходных PowerShell-файлов и diff check прошли. Реальный `backup-fence` из INF-18 не повторялся: SQL и maintenance helpers не менялись. Общая проверка приложения остаётся прежней — эта правка затрагивает только порядок обработки копии. Смежные B/INF и QA приняли изменение без открытых замечаний INF-20. Новых точек входа/команд нет, карта AGENTS.md остаётся актуальной.
