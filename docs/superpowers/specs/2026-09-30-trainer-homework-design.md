# Тренажёр и сдача домашней работы

Согласовано в чате 30 сентября 2026: преподаватель заранее определяет задачи, версию Java, зависимости, шаблоны и тесты. Ученик решает такие задачи на сайте; полное проектное ДЗ загружает для ручного ревью. Сохраняем существующий зелёно-песочный интерфейс и материалы.

## Результат первой версии

- На страницах заданий появляются назначенные упражнения и переход «Решать». Отдельный экран содержит условие, файлы решения, Monaco с доступным текстовым редактором при сбое загрузки, запуск примеров и полную проверку.
- Черновики и попытки связаны с учеником, занятием, упражнением и версией упражнения. Ученик видит компиляцию, результаты отдельных тестов, ожидаемый и фактический результат. Преподаватель видит отправленный код и результаты.
- Преподаватель назначает готовые упражнения занятию, указывая «На занятии» или «Домашняя практика». Определения упражнений и окружений — отдельные версионируемые файлы в training, вне dist. README описывает добавление задания и подготовку зависимостей.
- Два существующих упражнения ListTask и GroupingTask включены в занятие Михаэля. Новые ученики и занятия не наследуют их автоматически.
- Страница ДЗ принимает ZIP, Java, TXT, Markdown или PDF до 20 МиБ, комментарий и необязательную HTTPS-ссылку на репозиторий. Каждая сдача сохраняется отдельно. Файлы не распаковываются и не исполняются. Преподаватель скачивает их и задаёт «Проверено» или «Нужна доработка» с обратной связью.

## Окружение проверки

Каждое упражнение выбирает подготовленный профиль: версия JDK и точные Maven-координаты библиотек, включая явно перечисленные транзитивные зависимости. Подготовка загружает библиотеки из Maven Central в приватный кеш. Ученик не меняет профиль, сборочные команды или тесты. Поддерживаются несколько Java-файлов и пакеты, в том числе разрешённые профилем annotation processors.

Основной сервер остаётся Node.js. Проверка вынесена в модуль с очередью и отдельными процессами: Docker для серверного окружения, ограниченный локальный JDK 21 как режим разработки при недоступном Docker. Локальный режим использует Java policy с раздельными правами доверенного проверяющего кода и ученических классов; это не замена системной изоляции на хостинге. Ни один режим не запускает редактируемый учеником main как доказательство прохождения тестов.

Для Docker: запуск без сети, без доступа к данным кабинета, непривилегированный пользователь, ограничения памяти, CPU, процессов, вывода и времени; временные рабочие файлы очищаются. При недоступном окружении результат «проверка недоступна», а не успех. Задания выполняются последовательно с ограниченной очередью.

## Границы

Эта работа не публикует сайт и не покупает хостинг. Существующий сервер продолжает слушать localhost. Полноценная аутентификация и серверное разделение прав перед публичным размещением — отдельный этап; переключатель ученического вида не является системой доступа. Текущий каталог и API предназначены для локальной проверки реализации. Для публичного запуска локальный JDK-режим запрещён.

## Данные и совместимость

Существующий data/mentoring.json не меняется. Дополнительные данные хранятся под data/practice; файлы сдач — вне статического каталога и доступны через API скачивания после проверки принадлежности ученику и занятию. Записи атомарны. Размер кода ограничен; допустимы только объявленные файлы упражнения. Сервер проверяет принадлежность занятия ученику во всех новых маршрутах.

## Проверки

Должны быть проверены: неправильное и правильное решение обоих упражнений; ошибка компиляции; зависание и чрезмерный вывод; задача с внешней библиотекой; отсутствие утечки тестов в ученический ответ API; сохранность черновиков/попыток после перезапуска; изоляция записей учеников и занятий; загрузка, скачивание и ревью ДЗ; неверные расширения, превышение размера и опасные имена файлов; узкий экран и смена упражнения с несохранённым кодом.
