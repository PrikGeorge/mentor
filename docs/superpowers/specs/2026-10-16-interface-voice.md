# UX-29. Голос интерфейса: тренажёр, домашняя работа, занятие

Статус: утверждено владельцем 16.10.2026. Автор находок: `ux-designer` (16.10.2026). Правила: [docs/team/2026-10-16-mentor-voice.md](../../team/2026-10-16-mentor-voice.md), словарь — `.claude/agents/ux-designer.md`.

## Проблема

В тренажёре и сдаче домашней работы ученику пишут то на «ты», то на «вы», а в сообщениях об ошибках встречается протокольный жаргон: «ключ попытки», «исполнитель заданий», «ревизия», «сигнатура ZIP», «экспортировать». В интерфейсе преподавателя остались слова не из словаря: «Экран ученика», «отзыв», «условия задач».

## Правило

- Ученику — «ты»: экраны и сообщения, которые видит только ученик (отправка решения, черновик, переход на новую версию упражнения, загрузка домашней работы, выход с несохранённым кодом).
- Преподавателю — «вы»: редактор текстов занятия, карточка ученика, назначения.
- Общие экраны, где ту же строку видит преподаватель в своём интерфейсе (тренажёр, история попыток, код сданной работы, раздел ревью) — безлично. Экран ученика в предпросмотре говорит голосом ученика («ты»).
- «Ревизия» в тексте для ученика — «версия упражнения»; «экспортировать» — «скачать» (кнопка сохраняет файл `practice-source.json`).

## Что не входит

- Системные метки: знаки оценки, статусы занятий, попыток и сдач, «Только вам / Видно ученику», «Ожидалось / Получено», `homework-due.ts`, тон «чей ход».
- Интерфейс преподавателя, где «вы» уже верно (назначения упражнений, формы занятия).
- Общие сообщения `core/api-error.ts` («Обновите страницу и повторите» и др.) показываются обеим ролям на всех экранах. Их перевод в безличную форму — отдельная задача, потому что затрагивает каждый экран и десятки тестов.
- Тексты упражнений и комплектов в `private/` — их правит другая задача.

## Критерии приёмки

1. Все строки из таблиц заменены, смысл и действия кнопок не изменились.
2. В `frontend/src/app/practice`, `homework`, `core/practice-exit*` нет обращения на «вы» к ученику и слов «ключ», «исполнитель», «ревизия», «экспорт» в текстах для ученика.
3. Unit, lint, build и Playwright UI зелёные; тесты, которые ищут старые тексты, обновлены.

## Открытые вопросы владельцу

1. Кнопка «Экран ученика ↗». Рекомендация: «Кабинет ученика ↗» — коротко, а баннер внутри уже говорит «Предпросмотр кабинета ученика · только чтение». Вариант: «Предпросмотр ↗».
2. «Экспортировать» → «Скачать» во всём тренажёре. Рекомендация: да, кнопка просто сохраняет файл.
