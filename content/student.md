## 03/07 · Задание 2: отчёт по книгам

Изучи модель `Loan` и заготовку метода в `GroupingTask.java`. Одна запись `Loan(bookId, readerId)` — одно появление книги в списке читателя. Повтор такой записи разрешён во входных данных: именно такие ошибки нужно обнаружить.

<!-- task-code:GroupingTask:practice -->

Допиши `duplicateReport`. Используй обычные циклы и коллекции `Map`/`Set`. Сначала собери промежуточные сведения отдельно по каждой книге, затем сформируй результат. Не изменяй входной список.

Правила результата:

- Книга попадает в отчёт, если её ID встречается во входе не меньше двух раз, даже у одного читателя.
- На одну такую книгу нужна ровно одна строка `DUPLICATE book=<ID> readers=<список>`.
- В строке только читатели этой книги. Каждый читатель указан один раз, ID по возрастанию.
- Строки идут по возрастанию ID книги. Книги с одной записью в отчёт не входят.

Примеры входа и требуемого выхода:

```text
Вход: (40,9), (40,9)
Выход:
DUPLICATE book=40 readers=[9]

Вход: (40,9), (40,2)
Выход:
DUPLICATE book=40 readers=[2, 9]

Вход: (70,5), (40,9), (70,5), (40,2), (90,1)
Выход:
DUPLICATE book=40 readers=[2, 9]
DUPLICATE book=70 readers=[5]
```

Для пустого входа и одной записи `(40,9)` результат — пустой список строк. Изменение порядка входных записей не должно менять отчёт.

Покажи преподавателю промежуточные сведения после первых трёх записей смешанного примера, затем после всех пяти. Объясни, почему число записей и число разных читателей могут различаться. После реализации запусти шесть проверок в `main`: ожидается `PASS: 6 grouping checks`.

Если готов только сбор данных, покажи промежуточные карты и вручную составь итог. Вместе с преподавателем решите, когда переходить к Library; упражнение можно завершить дома.

## 07/07 · Как запускать учебные заготовки

Открой PowerShell в папке этого урока. Нужен JDK 17 или новее; примеры проверены на JDK 21 с целевой версией 17.

```powershell
New-Item -ItemType Directory -Force -Path '.\build\student' | Out-Null
javac --release 17 -encoding UTF-8 -d '.\build\student' '.\code\student\ListTask.java' '.\code\student\GroupingTask.java'
java -cp '.\build\student' ListTask
java -cp '.\build\student' GroupingTask
```

Запускай каждый `java` отдельно. Обе заготовки компилируются, но **до твоей работы не проходят запуск**: в первой нужно найти ошибку операции над списком, во второй метод ещё не реализован и содержит явную заглушку. После исправлений ожидаются сообщения `PASS`, указанные в заданиях. Тестовые методы `check` менять не нужно.
