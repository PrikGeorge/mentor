В PowerShell перейти в эту папку:

```powershell
Set-Location -LiteralPath 'C:\Users\George\Desktop\Dev\Learning\Mentoring\Михаэль\Сопровождение\Уроки\2026-09-27'
New-Item -ItemType Directory -Force -Path '.\build\teacher', '.\build\student' | Out-Null
javac --release 17 -encoding UTF-8 -d '.\build\teacher' '.\code\teacher\ListSolutions.java' '.\code\teacher\GroupingSolution.java'

javac --release 17 -encoding UTF-8 -d '.\build\student' '.\code\student\ListTask.java' '.\code\student\GroupingTask.java'
```

Выполнять команды последовательно; если компиляция завершилась ошибкой, не считать запуск старых `.class` проверкой текущих исходников. Нормальный вывод двух эталонов: `PASS: 12 list checks`, `PASS: 9 grouping checks`.

Отдельно проверить стартовое состояние ученических заготовок:

```powershell
java -cp '.\build\student' ListTask
java -cp '.\build\student' GroupingTask
```

Оба запуска **изначально должны завершиться с кодом 1**: `ListTask` — `UnsupportedOperationException` при `sort`, `GroupingTask` — `UnsupportedOperationException: TODO: implement duplicateReport`. Это намеренный старт упражнения, а не готовые решения. Не показывать этот абзац вместо вопроса на прогноз в начале урока.

Учебные файлы не используют пакеты, Maven, JUnit и Lombok. Проверки выбрасывают `AssertionError` при несовпадении, поэтому флаг `-ea` не нужен. Выходные `.class` создаются только в папке `build` этого урока.
