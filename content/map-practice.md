### Задание 1: Подсчёт частоты символов

**Условие:** Дана строка `"абракадабра"`. Подсчитай, сколько раз встречается каждый символ, используя HashMap.

**Подсказка:** `Map<Character, Integer>`. Для каждого символа: если есть — увеличь счётчик, если нет — поставь 1.

### Задание 2: Группировка студентов по оценкам

**Условие:** Дан список студентов с оценками. Сгруппируй их по оценке: Map<Integer, List<String>>.

**Подсказка:** Используй `computeIfAbsent` для автоматического создания списка.

### Задача 3: Словарь

**Условие:** Создай англо-русский словарь (HashMap). Добавь 7 слов, реализуй перевод в обе стороны (для обратного перевода — создай второй Map).

### Задача 4: Инвертирование Map

**Условие:** Дана Map `{1: "один", 2: "два", 3: "три"}`. Создай обратную Map `{"один": 1, "два": 2, "три": 3}`.

### Задача 5: Два числа с заданной суммой (Two Sum)

**Условие:** Дан массив чисел `[2, 7, 11, 15]` и целевая сумма `target = 9`. Найди два числа, которые дают эту сумму. Верни их индексы.

### Задача 6: Анаграммы

**Условие:** Две строки — анаграммы, если состоят из одних символов (например, "listen" и "silent"). Проверь, являются ли две строки анаграммами.

### Задача 7: Группировка анаграмм

**Условие:** Дан список слов. Сгруппируй анаграммы вместе: `["кот", "ток", "сон", "нос", "abc", "cab"]` → `{кот=[кот, ток], нос=[сон, нос], abc=[abc, cab]}`.

### Задача 8 (сложная): Кэш с ограниченным размером

**Условие:** Реализуй простой кэш на основе HashMap, который хранит не более N записей. При превышении — удаляет самую старую запись (FIFO).

### Задача 9: LinkedHashMap как кэш последних запросов

**Условие:** Реализуй кэш последних 5 поисковых запросов.

### Задача 10 : Подсчёт слов с сохранением порядка

**Условие:** Подсчитай частоту слов в тексте, сохраняя порядок первого появления (LinkedHashMap) и в алфавитном порядке (TreeMap).

### Задача 11: Реализация LRU-кэша на LinkedHashMap

**Условие:** Создай LRU-кэш (Least Recently Used) на 3 элемента. При обращении к элементу он перемещается в конец. При переполнении удаляется наименее недавно использованный.


### Задача 12: Объединение двух TreeMap

**Условие:** Объедини две TreeMap, при совпадении ключей — сложи значения.
